## Cómo usar
1) Abre `index.html` en tu navegador (doble clic).
2) Para traducir: usa el traductor del navegador (Click derecho → Traducir al inglés/español)
3) Para publicar:
    - Netlify: arrastra la carpeta `nexoit_site` al panel de Netlify.
    - Vercel/GitHub Pages: sube los archivos al repo y despliega.

## Personalizar
- Cambia el WhatsApp en: `assets/js/main.js` -> `COMPANY_WHATSAPP`
- Cambia correo: en `index.html` (mailto: nexoit90@gmail.com)
- Portafolio: sección `#portafolio` en index.html
- Proyectos: crea carpeta en `assets/img/projects/` para cada proyecto
- Casos de éxito: edita `casos-exito.html`
- Actualiza dominio en: `robots.txt` y `sitemap.xml`
- Fundadores: sección `#equipo` (foto, nombre y descripción)
